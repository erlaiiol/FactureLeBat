# Phase 1.7-1 — App Store Connect: Paid Apps Agreement, Subscription Group & Products

**Status (2026-09-28): done, except the sandbox tester.** Completed by
the user via their own Claude Cowork session (browser access to App Store
Connect) — see the checked items below for exactly what exists now and
the real values, and [1.7-2](./1.7-2-backend-apple-purchase-verification.md)'s
"What shipped" for how they've already been wired into `.env`/`infra/.env`.

## Objective

Unblock everything downstream. StoreKit products cannot be created —
literally: the "In-App Purchases" / subscription tab in App Store Connect
stays disabled — until the "Apps payantes" (Paid Apps) agreement is
active. Nothing in 1.7-2/1.7-3 can be exercised against real Apple
infrastructure until this is done, though their code can be written
against a StoreKit Configuration file in parallel (see 1.7-3).

## This entire phase is external and non-code

Everything below happens in App Store Connect / Apple's business portal,
by the account holder, not by any Claude Code session. Claude Code has no
browser and cannot enter legal or banking data on your behalf.
